# 로얄 스매시

대포 뒤에 서서 정면의 왕궁 원탁 위에 쌓인 장난감 블록을 구슬로 쏴 무너뜨리는 3D 게임이에요. 블록이 모두 탁자 아래로 떨어지면 끝나요. 태블릿에서 아이도 쉽게 할 수 있게 만들었어요.

- 하러 가기: https://2juwon.github.io/royal-smash/
- 조작: 블록을 톡 누르면 구슬이 그 자리로 날아가요. 옆으로 밀면 탁자를 돌아봐요.
- 모드: 스테이지 12단계(쏜 구슬 수로 별) / 무한 블록 놀이

## 만들기

```
npm install
npm run build   # src/main.js 를 three.js·cannon-es 와 묶어 src/v2.html 에 넣고 index.html 생성
```

`index.html` 한 파일이면 그대로 동작해요(외부는 Jua 글꼴만).
